4.2.3

Paragraph Headings (Tajuk Perenggan)

Tajuk perenggan dalam HTML digunakan untuk menampilkan teks dengan pelbagai saiz tajuk. Penggunaan tajuk membantu menyusun hierarki kandungan laman web supaya lebih kemas, teratur, dan mudah dibaca oleh pengguna.

Ciri-Ciri Utama Paragraph Headings:

  • Terdapat 6 saiz tajuk daripada <h1> hingga <h6>.
  • Tag <h1> mewakili tajuk paling utama dan mempunyai saiz teks paling besar.
  • Tag <h2> hingga <h6> digunakan untuk tajuk sub-seksyen yang lebih kecil.
  • Setiap tajuk secara automatik membina ruang baris baharu di atas dan di bawahnya.

4.2.4

Banner, Frame dan Menu

BANNER

Banner diletakkan di bahagian atas laman web. Ia berfungsi sebagai tajuk utama atau grafik pengenalan yang menampilkan nama, logo, atau grafik tema sesebuah organisasi.

Contoh Paparan Banner Laman Web

FRAME

Frame membahagikan tetingkap paparan pelayar web kepada beberapa bahagian berasingan untuk memaparkan dokumen HTML yang berbeza secara serentak.

Bahagian Frame 1 (rows="30%")
Bahagian Frame 2 (rows="70%")

MENU

Menu mengandungi senarai pautan navigasi untuk memudahkan pengguna berpindah ke bahagian atau laman web lain.

Tag HTML Pembinaan Menu:

Tag <nav> mentakrifkan kawasan navigasi utama. Tag <ul> membina senarai tidak teratur (unordered list), dan tag <li> membina setiap item pautan dalam menu tersebut.

4.2.5

Pautan Teks dan Imej (Hyperlink)

Pautan (hyperlink) membolehkan pengguna beralih dari satu dokumen HTML ke dokumen HTML yang lain, atau ke lokasi lain dalam laman web yang sama. Pautan boleh dibuat dalam bentuk Teks atau Imej menggunakan tag pautan <a href="...">.

1. Pautan Teks (Text Link)

Pengguna mengklik pada perkataan atau frasa teks untuk membuka laman sasaran.

<a href="galeri.html">Klik Ke Galeri</a>

2. Pautan Imej (Image Link)

Elemen gambar <img> dimasukkan di dalam tag pautan <a> supaya gambar tersebut boleh diklik.

<a href="utama.html"><img src="home.png"></a>

Analisis Ralat Lazim Murid (Common Mistakes Panel)

1. Keliru Tag <img> & Tag <image>

Murid kerap menaip perkataan penuh <image> berbanding tag spesifik HTML <img> semasa membina pautan imej.

2. Tertinggal Tag Pembungkus <a>

Murid meletakkan elemen imej tanpa membungkusnya di dalam tag <a href="..."> menyebabkan pautan imej tidak boleh diklik.

3. Struktur Tag Menu <nav>

Murid kerap terlupa bahawa item menu <li> mesti berada di dalam tag <ul> dan <nav>.
